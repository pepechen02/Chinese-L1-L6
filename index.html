二、第一單元　當我們同在一起

第一課　你我之間課本 p.13
修辭研究室轉化（擬人）
意思：將不具人類特徵的事物，以人類的觀念、性格、情感等，來思考或想像。
①春天來了，百花對著旅人展開了笑顏，蝴蝶穿梭花叢間跳起了迎賓舞。
→ 花和蝴蝶如人類般，做出了迎接客人的動作。
②咸豐草在微風中笑歪了腰。
→ 咸豐草隨風飄搖的姿態，像人類開心的模樣。

✏️ 修辭花嚕米

轉化原子筆告訴鉛筆要堅定；相機告訴手機要專一；抹布告訴衛生紙要耐勞；海報告訴拼圖要獨立。
（把物品當成人，會「說話」、有性格）
類疊鉛筆告訴原子筆要隨和；手機告訴相機要多元；衛生紙告訴抹布要犧牲；拼圖告訴海報要團結。
（「告訴……要……」句型重複出現）
映襯原子筆告訴鉛筆要堅定，鉛筆告訴原子筆要隨和。／刺蝟愛上了一顆氣球，但牠不能擁抱它。
（堅定↔隨和；愛上↔不能擁抱，兩種相反的情況對照）
📝 小小練習：哪一個句子使用「擬人」？
答案：② 大地穿上了秋風編織的新衣。（①「果實如下雨般紛紛落下」是譬喻）
第二課　風起，大家都在課本 p.28
修辭研究室譬喻
意思：使用「打比方」的方法，使文章內容表達得更具體、更生動。
辨認：常有「像、如、好像、就像、一樣」等詞。
①下雨了，五顏六色的雨傘如花朵紛紛綻放，把雨景增添得更有趣味。
→ 把開雨傘比喻成開花。
②太陽像一個火球，發光發熱，照亮了大地。
→ 把太陽具體化，比喻成火球。

✏️ 修辭花嚕米

譬喻
1. 走在校園裡，到處縈繞著風的顏色。有的在遠處，像是樹梢的微風。
2. 老師彈風琴……就像從不同方向吹來的風，將落葉、花絮都飄起來。
3. 聽著音樂，真的就像看見了有顏色的風。
感嘆沒關係，當孤單感覺來臨時，試著回想風的顏色，想像自己是一陣微風，來，加入風的隊伍裡，產生更強的威力吧！
類疊1. 讓耳朵和內心，聽見自己，也聽見別人的音樂。
　　　2. 風起，你在，大家都在。
（同一個詞連續重複，加強語氣）
📝 小小練習：哪一個句子使用「譬喻」？
答案：② 螞蟻大隊就像大力士一樣，一起搬動著美味的食物。（①青蛙張開大嘴開心唱歌是擬人）
第三課　廉頗與藺相如課本 p.43
修辭研究室感嘆
意思：當人遇到喜、怒、哀、樂的事情時，常會以呼聲來表達情感，稱為感嘆。
辨認：常有「！」，或「啊、哇、唉、吧」等語氣詞。
①發生事故後，這個商場幾乎不再出現人潮，太驚人了吧！
→ 用感嘆來表達「驚訝」。
②你看！這是一棵多麼高大的樹哇！
→ 用感嘆來表達「感受」。

✏️ 修辭花嚕米

感嘆
1. 我是以國家安全為重，才躲著廉頗，不想和他發生衝突，並非怕他！
2. 我是一個氣量小、見識少的人，不知道您為了顧全大局對我如此包容，請責罰我吧！
設問
1. 我連秦王都不怕了，怎麼會怕廉頗將軍呢？
2. 你們想一想，強大的秦國為什麼不敢攻打我們趙國？
3. 如果我們兩人相互爭鬥，因而造成國家動盪、社會不安，不是正好讓秦國有機會出兵嗎？
（用疑問句發問，引起注意；1、3 的答案在問題反面→激問）
頂真他公開羞辱您，您卻一味閃躲。
（前一句的結尾，就是後一句的開頭）
📝 小小練習：用「感嘆」寫出小美看到剛回國的小表妹時，心裡開心的感受。
參考答案：「哇！好久不見，妳長這麼高了！」（只要有表達開心的呼聲與「！」即可）

三、第二單元　生活大小事

第四課　來場快樂的桌遊課本 p.61
修辭研究室轉化（形象化）
意思：轉化可分為擬人、擬物、形象化三種。形象化就是將抽象的事物視為具體可見的事物。
①收集生活中美好的時光。
→ 將抽象的「時光」視為具體可收集的事物。
②我們披著夜色，踏著愉快的腳步，朝著家的方向前進。
→ 將「夜色」轉化成具體事物才能「披」。

✏️ 修辭花嚕米

轉化
1. 玩桌遊容易炒熱氣氛。（氣氛看不到，像食物一樣能「炒熱」→形象化）
2. ……一起玩桌遊，很快就能打破年齡的界線。（界線是抽象的，像東西可被「打破」）
譬喻近年來，「桌遊店」如雨後春筍般出現……
設問你知道什麼是「桌遊」嗎？它其實就是桌上遊戲……
（有問有答→提問）
📝 小小練習：哪一個句子使用「形象化」？
答案：① 活動熱絡了情感，炒熱了氣氛。（②向日葵抬起了頭、望著太陽微笑是擬人）
第五課　超級英雄課本 p.80
修辭研究室設問（激問）
意思：寫文章時，用疑問句來發問，藉此引起讀者的注意。設問可分為提問、激問、疑問。表示答案在問題的反面，就是「激問」。
①他最愛的是什麼？就是蜂蜜。
→ 提問：有問有答。
②他難道不清楚闖紅燈是違法的事情嗎？
→ 激問：肯定他知道闖紅燈是違法的。
③這些舊書要不要回收呢？
→ 疑問：想得知舊書應該如何處理。

✏️ 修辭花嚕米

設問
1. 我想要找今天看的那一部片子，為什麼就是找不到呢？（疑問）
2. 「違法？」銳邦不明白自己想讓大家免費觀賞電影，怎麼就違法了？
3. 如果大家都在網路上看免費電影，那麼拍電影的人不就無法得到應得的利潤？（激問）
誇飾他的腳步飛快，媲美閃電俠，連眼神都比超人發出的光束還要閃亮。
（把事物說得誇張、超過事實，讓人印象深刻）
譬喻銳邦不禁嘴角上揚，感覺自己像拯救世界的超人一樣威風。
轉化銳邦的「超人夢」，就此畫下句點。
（夢想是抽象的，像文章一樣能「畫句點」→形象化）
📝 小小練習：哪一個句子使用「激問」？
答案：① 你不道歉，他會原諒你嗎？（答案在反面：不會原諒）
②「你知道太陽距離地球有多遠嗎？」是疑問；③「天還早嗎？不早了，公雞都叫了。」是提問（有問有答）。
第六課　世足賽的贏家課本 p.96
修辭研究室映襯
意思：把兩種相反的觀念或事實並列做比較，能增強文句的語氣，也能凸顯作者要表達的觀念。
①爸爸說：「孩子是父母沉重又甜蜜的負擔。」
→ 「沉重」和「甜蜜」意思相對。
②我們育幼院的院長一生致力於照顧孩子，是平凡的偉人。
→ 「平凡」和「偉人」意思相反。

✏️ 修辭花嚕米

映襯臺灣雖非足球強國，卻沒有在這場盛會中缺席。
（非強國↔沒缺席，形成對比）
譬喻世界盃足球賽就像一場球技與時尚的嘉年華，吸引著千百萬人的目光。
轉化
1. 臺灣在球員的更衣室贏了自己的世界盃！（把更衣室、世界盃寫成能「贏」的比賽，帶有人的情感）
2. 「臺灣製造」(Made in Taiwan) 的金字招牌，也在世人眼中閃閃發亮。（把名聲這種抽象的事物，寫得像會發光的東西）
類疊
1. 每個環節都是關卡，每個關卡都需要突破。
2. ……在世人眼中閃閃發亮。
📝 小小練習：哪一個句子使用「映襯」？
答案：① 這家商店裡什麼都有，但是我口袋裡沒錢。（「什麼都有」↔「沒錢」相對）
②「有志者事竟成」是俗語，不是映襯。

四、修辭小辭典（總整理）

修辭意思辨認線索
轉化（擬人）把沒有人類特徵的事物，當成人來寫（有動作、情感、性格）。物品會說話、笑、跳舞、穿衣服
轉化（形象化）把抽象的事物（時光、夜色、氣氛）當成具體看得見、摸得到的東西。披著夜色、炒熱氣氛、打破界線
譬喻打比方，讓內容更具體生動。像、如、好像、就像……一樣
感嘆用呼聲表達喜怒哀樂的情感。！、哇、吧、啊
設問用疑問句發問引起注意。分提問（有問有答）、激問（答案在問題反面）、疑問（真的想知道答案）。？，看有沒有答案、答案在不在反面
映襯把兩種相反的觀念或事實放在一起比較，強調想表達的意思。沉重↔甜蜜、平凡↔偉人
類疊（補充）同一個字詞或句子連續重複出現，加強語氣。聽見……聽見……、閃閃、都是……都
頂真（補充）前一句的結尾，當作後一句的開頭。……您，您……
誇飾（補充）故意說得誇張，超過事實，讓人印象深刻。媲美閃電俠、比光束還閃亮
💡 考前小撇步
  1. 先找記號：像／如→譬喻；「！」→感嘆；「？」→設問。
  2. 設問再細分：有問有答＝提問；答案在反面＝激問；真的想知道＝疑問。
  3. 轉化看對象：物品像人→擬人；抽象東西變得具體→形象化。
  4. 映襯看對比：有沒有一組意思相反的詞？

質2 個讀音
ㄓˊ
  1. 事物的根本特性。如：本質（ㄅㄣˇ ㄓˊ）、特質（ㄊㄜˋ ㄓˊ）、流質（ㄌㄧㄡˊ ㄓˊ）。
  2. 人的天性稟賦。如：資質（ㄗ ㄓˊ）、氣質（ㄑㄧˋ ㄓˊ）。
  3. 樸實的本性。如：質樸（ㄓˊ ㄆㄨˇ）、文質彬彬（ㄨㄣˊ ㄓˊ ㄅㄧㄣ ㄅㄧㄣ）。
  4. 詢問。如：質問（ㄓˊ ㄨㄣˋ）、質詢（ㄓˊ ㄒㄩㄣˊ）、質疑（ㄓˊ ㄧˊ）。
ㄓˋ
  1. 以人或財物作為抵押。如：質押（ㄓˋ ㄧㄚ）。
  2. 被抵押的人或物。如：人質（ㄖㄣˊ ㄓˋ）。
💡 記法：「抵押」的意思讀 ㄓˋ，其他大多讀 ㄓˊ。
